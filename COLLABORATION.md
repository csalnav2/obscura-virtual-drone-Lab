# Collaboration and access to the full drone implementation

Updated September 27, 2026. The public OBSCURA materials and synthetic preview
are separate from the complete unpublished Virtual Drone Lab implementation.

**The only offered route to the full unpublished code is an approved
collaboration.** Access is not automatic after starring, forking, opening an
issue, downloading the preview or completing a form.

## Submit a non-confidential request

Use the [Collaboration request form](https://github.com/csalnav2/obscura-metamaterial-observability-lab/issues/new?template=collaboration.yml)
and include:

1. Your GitHub identity and optional public affiliation/portfolio.
2. A specific research question or engineering contribution.
3. A concrete deliverable, evaluation method and proposed timeline.
4. Relevant experience or prior work.
5. The minimum access needed and why public documentation is insufficient.
6. Proposed attribution, publication and confidentiality expectations.

Do **not** post private contact information, secrets, unpublished enabling
technical details, patient/personal data or third-party confidential material.
The maintainer will arrange a private communication channel if the proposal is
suitable. No public issue constitutes an NDA or grants a license to private code.

## Review and access sequence

1. The maintainer reviews fit and scope.
2. Both parties agree on contribution, attribution, confidentiality and access
   terms in writing as appropriate to the work.
3. Access starts at the minimum useful level: sanitized data, frozen executable,
   hosted interface or one module.
4. Full-source access requires explicit approval and an invitation to a **separate
   private repository**. Work through branches and reviewed pull requests there.
5. Document dependencies, seeds, units, test results and changes. End or narrow
   access when the agreed work concludes, subject to the agreed terms.

Do not grant repository access automatically from an issue or workflow, and do
not place private files in a public PR—even if it is a draft.

## Useful contributions

- Independent optics, quantum-information and numerical-method audits.
- Matched weather/observer robustness experiments and uncertainty estimates.
- Cross-solver or experimentally calibrated comparison designs.
- Trajectory/skill-memory evaluation with provenance and removal controls.
- Interface accessibility, camera behavior and reproducibility tooling.

## Public files remain public

The existing [Apache-2.0 LICENSE](LICENSE) governs the public repository. This
access process concerns the unpublished implementation and does not override
permissions already granted for public material. See
[public/private boundaries](docs/PUBLIC_PRIVATE_BOUNDARY.md).
